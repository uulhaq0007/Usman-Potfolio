An internal tool for managing responses to requests for proposal, built on Material UI
with a persistent sidebar shell and a full light/dark theme. Covers an overview dashboard
with live metrics and charts, a project tracker with per-response progress, a sectioned
proposal composer, plus template, knowledge base and resource libraries — every screen
captured in both themes.
